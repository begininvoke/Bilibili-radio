# 智能省流后台播放助手

## 项目简介

智能省流后台播放助手是一款适用于 Edge 浏览器的扩展插件，实现"后台纯音频、前台全画质"的智能切换，达到省流目的，并提供优雅的流量监控 UI。

## 核心功能

- **智能播放模式切换**：标签页在后台时自动切换为仅音频模式，前台时恢复全画质
- **干扰净化与背景管理**：自动处理视频播放页面的非必要视觉元素，减少资源占用
- **流量消耗实时监控**：实时统计流量消耗和节省情况，提供直观的可视化界面

## 安装方法

### 方法一：通过开发者模式加载

1. 克隆或下载本项目到本地
2. 打开 Edge 浏览器，进入 `edge://extensions/`
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择本项目的根目录
6. 扩展将被加载到浏览器中

### 方法二：通过构建后的文件加载

1. 安装依赖：`npm install`
2. 构建项目：`npm run build`
3. 打开 Edge 浏览器，进入 `edge://extensions/`
4. 开启右上角的"开发者模式"
5. 点击"加载已解压的扩展程序"
6. 选择 `dist` 目录
7. 扩展将被加载到浏览器中

## 使用说明

1. **功能开关**：点击扩展图标，在弹出的界面中可以开启或关闭以下功能：
   - 智能省流模式
   - 自动净化弹幕/背景
   - 流量监控

2. **查看流量数据**：在弹出的界面中可以查看：
   - 已节省流量
   - 实时下行速率
   - 本次会话流量
   - 总计流量
   - 最近5条视频流请求记录

3. **模式切换**：
   - 当标签页处于前台时，视频会以全画质播放
   - 当标签页切换到后台超过3秒后，视频会自动切换为仅音频模式
   - 当标签页切回前台时，视频会恢复全画质播放

## 技术实现

- **框架**：原生 JavaScript
- **构建工具**：Vite
- **扩展类型**：Manifest V3
- **核心 API**：
  - `chrome.webRequest`：用于拦截和修改视频请求
  - `chrome.storage`：用于存储流量数据和用户设置
  - `chrome.tabs`：用于监听标签页状态变化
  - `document.visibilityState`：用于监听页面可见性变化

## 适配网站

- **优先适配**：Bilibili (B站)
- **次级适配**：YouTube

## 注意事项

1. 本扩展仅在 Edge 浏览器 (Chromium 内核) 90+ 版本上测试通过
2. 由于不同视频网站的实现方式不同，可能会出现适配问题
3. 流量统计数据为估算值，可能与实际消耗存在差异
