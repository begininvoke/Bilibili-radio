# 首页、歌单操作与歌曲详情页调整

## 背景

首页仍有推荐和热门视频 mock 数据，曲目行的队列与歌单操作不够明确，歌曲详情页仍展示示例章节和弹幕精选。当前目标是把前端展示从 mock 过渡到真实数据或明确的开发中状态。

## 本轮变更

- 首页：
  - 删除“热门视频”板块。
  - “为你推荐”不再渲染 mock 卡片，改为文案：`目前正在开发中，请您看看其他内容。`
  - 新增“我的播放次数 Top 10”，只从最近播放里的用户本地播放记录聚合，按 `recentPlayCount` 倒序展示前 10 条。
  - 播放次数展示当前用户自己的播放次数，例如 `已播放 12.3万 次`，不是 B 站视频总播放量 `playCount`。
  - 删除未使用的 `src/mock/data.ts`。

- 曲目行：
  - 保留爱心为喜欢。
  - `+` 明确表示加入播放队列。
  - 新增列表图标按钮表示添加到歌单。
  - 多 P 视频级 Track 点击歌单按钮时先展开分 P，避免把整个 BV 当作一首歌误加入。
  - 分 P 行现在支持标题播放、喜欢、加入队列、添加到歌单。

- 歌曲详情页：
  - 增加当前曲目的“加入队列”“添加到歌单”“下载”操作按钮。
  - `弹幕精选` 标签改为 `评论区`。
  - 字幕、简介、章节、评论区不再展示 fake 示例内容，统一显示接口开发中状态。

## 验证

- 运行 `npm run type-check`。
- 运行 `npm run build`。
