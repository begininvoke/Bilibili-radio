# 底部播放器缩放拥挤与 UP 跳转修复

日期：2026-08-08

## 问题

缩放或窗口变窄后，底部播放器仍按固定三栏展示，右侧音量、音质、倍速、歌词开关、色盘、字号、下载等控件都挤在 30% 宽度内，导致布局拥挤。

同时，点击 UP 名进入主页时，如果旧数据缺少 `ownerMid`，前端会尝试通过 BV 详情解析，但失败时没有任何提示，表现为“点击没反应”。

## 调整

- 底部播放器改为更弹性的三栏：
  - 左侧当前曲目信息可收缩。
  - 中间播放控制和进度条保留优先级。
  - 右侧辅助控件按宽度分档隐藏低频项。
- 在中等宽度下：
  - 隐藏桌面歌词按钮文字。
  - 隐藏底栏歌词色盘和字号调整。
  - 压缩图标按钮和播放按钮尺寸。
- 在更窄宽度下：
  - 隐藏喜欢按钮和未接入的画中画按钮。
  - 必要时隐藏整个右侧辅助区，保留播放核心控件。
- UP 跳转：
  - `useOpenOwner` 改为直接按 `/up/<mid>` path 导航。
  - 播放时后台补齐 `ownerMid`、UP 名、封面等元数据。
  - 点击 UP 失败时写入播放器状态提示，不再静默失败。

## 后续

如果要在窄宽度仍保留全部歌词设置，应做一个播放器设置弹出菜单，而不是把所有控件平铺在底栏。
