# 歌单详情隐藏封面 URL 输入

日期：2026-08-08

## 问题

歌单详情页把封面 URL 作为普通输入框展示出来，用户会直接看到 `https://i0.hdslb.com/...jpg` 这样的图片链接。这个字段属于内部数据，不应该出现在歌单编辑界面里。

## 调整

- 删除 Collection 详情页的封面 URL 输入框。
- 保留左侧封面预览。
- 封面来源改为内部自动选择：
  - 优先使用 Collection 自身的 `cover`。
  - 没有 Collection 封面时，回退到第一首曲目的 `cover`。
- “保存信息”现在只保存歌单名，不再暴露或提交封面 URL。

## 后续

如果以后要支持用户换封面，应做成“选择封面 / 使用当前曲目封面 / 上传图片”这类明确交互，而不是展示原始图片链接。
