# 随机播放、末尾回环与悬浮字幕字号实现记录

日期：2026-08-08

## 播放策略

- 顺序播放到队列末尾后不再停住，自动回到第 1 首继续播放。
- 随机播放改成一轮洗牌：
  - 当前轮内优先播放未出现过的曲目。
  - 播完一轮后重新生成下一轮随机顺序。
  - 不再只是每次随机抽一个非当前项，减少短队列频繁重复。
- 随机模式维护上一首历史：
  - 点击上一首会回到随机历史中的上一首。
  - 手动点击队列项会从待播随机列表中移除该项。
  - 队列新增、删除、清空、替换时同步重建或重映射随机状态。

## 悬浮字幕字号

- 新增 `lyricsOverlayFontSize` UI 状态，默认 30px，范围 22px 到 48px。
- 字号保存到 localStorage：`bili-radio:lyrics-overlay-font-size`。
- 底部播放器在悬浮歌词开启时显示字号控制：
  - `A-` 减小字幕
  - 当前字号
  - `A+` 放大字幕
- 悬浮歌词窗口自身也提供 `A-` / `A+` 控制按钮。
- Tauri `set_lyrics_window_payload` 和 `current_lyrics_window_payload` 增加 `fontSize` 字段。
- 悬浮歌词文本改用固定 px 字号变量，避免随窗口宽度隐式缩放。

## 明确不做

- 本次不新增播放模式。
- 本次不做随机权重、最近不重复 N 首或跨会话随机历史持久化。
- 本次不新增依赖。
